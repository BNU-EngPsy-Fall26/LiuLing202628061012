### 第 2 次试玩（2026-11-04，本人，Chrome）

| 条件 | 发现率 | 中位发现时间 |
| --- | --- | --- |
| 稳定参照 · 边缘 | 90% | 2883 ms |
| 稳定参照 · 中央 | 90% | 2421 ms |
| 均匀遮蔽 · 边缘 | 100% | 6098 ms |
| 均匀遮蔽 · 中央 | 100% | 2490 ms |

判断：仍接近天花板（90–100%），且均匀遮蔽竟高于稳定参照（1 个试次差异，噪声）。

→ 继续加难度：船只 18→26、位移 44→30 px，重新试玩。

## 校准判断标准

| 现象 | 处理 |
| --- | --- |
| 实验一高对比条件正确率 > 95% 且 RT 很短 | 说明太简单，缩小 ΔE 或增大集合 |
| 实验一两条件正确率都 < 60% | 太暗/太难，提高低对比亮度或减少集合 |
| 实验二稳定参照发现率 > 90% | 天花板，船只位移 72 → 56 px |
| 实验二三种模式都 < 25% | 地板，位移 72 → 96 px 或延长空白 |
| 实验二稳定参照与均匀遮蔽几乎无差别 | 参照层空白期透明度提高，或延长空白 |
