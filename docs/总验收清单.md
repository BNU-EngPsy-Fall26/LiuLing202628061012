## 2. 结果页逐项

- [ ] **2.1** 标题写「**三轮共 90 次判断**」（不是 0 次）

- [ ] **2.3** d′ 那一列的数字，和 `Store.rounds` 里的一致

**下面这三条是重点（今天改的就是它们）：**

- [ ] **2.4 ★ 三条评语跟着实际摆幅走**

  看你自己这一局的摆幅，对照下表：

  | d′ 摆幅 | 应该显示 |
  |---|---|
  | < 0.35 | 几乎没变 |
  | 0.35 ~ 0.70 | 有点起伏 |
  | **> 0.70** | **变化明显** |

  c 和准确率同理（c：0.20 / 0.50 为界；准确率：8 / 15 个百分点为界）

  **如果摆幅明显 > 0.70 却还写「几乎没变」→ 缓存没清干净，或者改漏了。立刻停下来告诉我。**

- [ ] **2.6 ★ 无论哪种情况，最后两句都在**

## 8. 发现问题怎么报

**不要自己改，也不要立刻让 AI 改。**

**先收集，一次改完。** 按这个格式记：

```
【在哪】结果页，三轮对比表下面
【我做了什么】玩完三轮，进结果页
【看到什么】d′ 摆幅 0.72，但评语写的是「几乎没变」
【我以为是】应该写「变化明显」
【截图】y
```

**唯一例外**：如果是**卡死、白屏、完全跑不动**，立刻停下来告诉我。
