# 工程心理学作业一：信号检测论交互式实验室

## 项目说明

本项目使用 HTML、CSS 和原生 JavaScript 实现，无后端依赖。作业包含登录、  
难度设置、大雾天红绿灯判断游戏、游戏结束、成绩分析和学习理解六个阶段。

项目提供两种运行方式：

1. 单文件提交版：直接双击 `作业一_提交版.html`，所有页面代码均包含在该文件中。
2. 多页面开发版：直接双击 `index.html`，通过页面之间的链接完成完整流程。

两种方式均可在 Chrome、Edge 等现代浏览器中直接运行，不需要安装依赖或启动服务。

## 完整流程

1. 登录页：输入学号、姓名，或选择游客模式。
2. 难度设置页：调整信号强度 `d'`，选择 20、50 或 100 次判断。
3. 游戏页：根据大雾中的红绿灯完成信号判断。
4. 游戏结束：显示本轮 `H`、`M`、`FA`、`CR` 数量。
5. 成绩页：显示混淆矩阵、击中率、误报率、`d'`、`c` 和准确率。
6. 学习理解页：通过可交互分布图理解 `d'`、`β`、`c`、`A'` 以及统计检验中的  
   `α`、`β` 区域。

## 核心功能

- 使用纯 CSS 绘制红绿灯刺激，并根据 `d'` 调整模糊、亮度、透明度和噪点。
- 按选择的轮次随机呈现信号与噪音，完整记录 `H`、`M`、`FA`、`CR`。
- 使用正态分布模型计算 SDT 指标：  
  `d' = z(H) - z(FA)`
- 使用对数线性修正计算统计量，并展示：  
  `d'`、`β = fSN(xc) / fN(xc)`、`c = -0.5[z(H) + z(FA)]`
- 使用交互式 SVG 分布图展示噪音/信号分布、`H₀/H₁` 分布、`α/β` 区域。
- 页面支持桌面和移动端布局。
