## 要改的四处

### 一、`dPrime` 的 P 要大写

契约定的拼法是 **`dPrime`（大写 P）**，和 Session 里的
`systemDPrime` / `metrics.dPrime` 保持同一套 —— 全项目只有一个约定。

改这三处：

```
'systemDprime'        →  'systemDPrime'
'r%dDprime'           →  'r%dDPrime'
'overallDprime'       →  'overallDPrime'
```

**注意 `C` / `Accuracy` / `PH` / `PFA` 那几个不用动**（它们本来就是对的）。

### 二、★ row 字典里加上 `payload`

就是数据库里那一列，**原样带出来**：

```python
'payload': row['payload'],
```

**为什么要带**：有些字段不在拆开的列里（比如某一轮的漏报数 M），
教师后台要靠这份 JSON 兜底。**不带的话那些地方会静默变成 null** ——
不报错、不崩溃，就是悄悄少一块。这类"静默失败"最难查。

### 三、`summary` 里如果也拼过 `Dprime`，一起改

搜一遍 `db.py` 和 `app.py` 里的 `Dprime`（小写 p），全部改成 `DPrime`。

### 四、检查 `/api/admin/summary` 的字段名

契约 6.1 里定的 `summary` 结构是：

```js
dprime:  { mean, sd, values },      // ← 这里是小写 d，因为是字段名不是变量名
c:       { mean, sd, values },
accuracy:{ mean, sd, values },
rounds: [ { round, dprimeMean, cMean, accuracyMean }, ... ]
```

**★ 这一处我故意用小写** —— 因为它们是"统计量的名字"（dprime 的均值），
不是 Session 里的字段。**和你改的那三处不冲突，别改错了。**

如果你现在拼的是别的名字，改成上面这套。

## ⑥ 空库时 `summary` 的均值返回 `null`，不要返回 `0.0`

**问题**（M13 那边发现的，它说得对）：

```
老师刚打开后台，还没有一个学生交卷
        ↓
summary 现在返回  dprime: { mean: 0.0, sd: 0.0, values: [] }
        ↓
界面上写「全班平均 d′ 0.00」
        ↓
老师会以为：这个班完全分不清危重患者
```

**但真相是"还没有数据"。** 这两个是不同的事实，不该显示成同一句话。

**改法**：

- 某个指标**一个值都没有**时，`mean` / `sd` 返回 **`null`**（不是 `0.0`）
- `values` 保持空数组 `[]`
- `n = 0` 时 `rounds` 里那三个对象的 `dprimeMean` / `cMean` / `accuracyMean`
  **也返回 `null`**
- **`sd` 在只有一个样本时仍然返回 `0.0`**（那是有意义的：样本只有一个，离散度为 0）
  —— **只有"零个样本"才返回 null**。这两个不一样，别一起改了。

**验证**：

```bash
# 用一个空库起服务
SDT_DB_PATH=/tmp/empty-test.db python3 app.py
# 另开终端拿 token 后：
curl -s 127.0.0.1:5055/api/admin/summary -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
```

**期望**：`n: 0`，`dprime.mean` 是 `null`（**不是 0.0**），`values` 是 `[]`。

```bash
# 再塞一条数据，确认只有一个样本时 sd 仍然是 0.0（不是 null）
```

**这两条要分别验**，因为它们都是"少一个判断就会静默出错"的地方。
