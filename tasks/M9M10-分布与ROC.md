## M9 `js/lab/dist.js` —— 两个分布与判定标准

### 控件

| 滑块 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 敏感性 d′ | 0 ~ 4，步长 0.1 | **1.5** | 契约 3.4 的系统设定 |
| 判定标准 c | −2 ~ 2，步长 0.05 | **0** | |

### 图表 `<div class="chart">`

用 `Chart.make()` 画：

1. **两条正态曲线**：噪音 `N(0,1)`，信号 `N(d′,1)`（用 `Utils.npdf` 逐点算）
2. **一条竖直的判定线**，位置在 `x = c`（注意：这里是 c 不是 xc，横轴就用 c 的尺度）
3. **判定线右侧的噪音曲线部分填红**（= 误报率 P(FA)）
4. **判定线左侧的信号曲线部分填绿**（= 漏报率 P(M)）
5. **悬停提示**：显示该点的 x 和两个分布的密度值

图例要标清楚哪条是噪音、哪条是信号。

### 图表下方：混淆矩阵 + SDT 指标

左右并排两个 `.card`：

**左：混淆矩阵**（用 `.cm-table`）

|  | 有信号 | 无信号 |
|---|---|---|
| 说"有" | H = ? | FA = ? |
| 说"无" | M = ? | CR = ? |

四个值**从当前 d′ 和 c 反算**（这就是"理想观察者在这个标准下会得到什么"）：

```
P(H)  = 1 - ncdf(c - d′/2)      // 判据在信号分布右侧的尾部
P(FA) = 1 - ncdf(c + d′/2)
P(M)  = 1 - P(H)
P(CR) = 1 - P(FA)
```

**★ 这四个公式请自己推导验证一遍再用**：拖动 c 滑块时，H 和 FA 必须
**同增同减**（判定线往左移，两个都变大）；拖动 d′ 时，H 变大而 FA 变小。

**右：SDT 指标**（四个小方块）

```
d′    1.50
β     1.00      ← β = exp(c · d′)
c     0.00
A′    0.85      ← 见契约 4.5 的公式，★ 分子里有 (1 + |pH − pFA|)，不能漏
```

**★ A′ 的公式以契约 4.5 为准**（本任务书早期版本漏了分子里的 `(1+|pH−pFA|)`，
那个错版本在 d′=1.5、c=0 时给 0.625，和真实 AUC 0.856 对不上）。

### 一句解读（固定文案，数字动态填）

> d′ 越大，两个分布分得越开。β > 1 = 严格，β < 1 = 宽松。
> **同一个 d′ 下，改变标准只会改 β 和 c，不会改 d′。**

## M10 `js/lab/roc.js` —— ROC 曲线

### ★ 这个面板的独特价值

老师那版只有一个工作点在 ROC 上滑。**你把玩家自己的三轮工作点也标上去** ——
**三个点在同一条曲线上滑动**，是"d′ 不变、c 在变"最直观的几何证据。

### 控件

| 滑块 | 范围 | 默认 |
|---|---|---|
| 敏感性 d′ | 0 ~ 4，步长 0.25 | 1.5 |
| 判定标准 c | −2 ~ 2，步长 0.05 | 0 |

### 图 `<div class="chart">`

1. **ROC 曲线**：横轴 P(FA)、纵轴 P(H)，用上面的公式逐点算
2. **对角线**（纯瞎猜的基准），用虚线、`--c-text-dim`
3. **当前工作点**：一个大圆点，用 `--c-primary`
4. **★ 玩家三轮的工作点**：从 `Store.rounds` 读，三个点分别用
   `--c-normal` / `--c-watch` / `--c-danger` 画（和轮次呼应），
   带文字标签「第一轮 / 第二轮 / 第三轮」
5. **悬停提示**：显示 P(FA)、P(H)

**如果 `Store.rounds` 是空的**（没玩过就进来了），就不画那三个点，
在图下方加一句小字：「玩完三轮再回来看，这里会标出你自己的三个工作点。」

### 图下方

- 一行：`AUC = ?`，并说明「0.5 = 随机，1.0 = 完美」
- 一个 `.card`，写这句话（数字动态填）：

> **三轮里你的 d′ 没怎么变，所以三个点大致落在同一条曲线上。**
> **但它们的位置不同 —— 那是你的标准 c 在移动。**
> **同一条曲线 = 同样的能力；曲线上不同的点 = 不同的态度。**

（如果 `Store.rounds` 为空，这段话换成一句提示。）

### 第二张图 `<div class="chart-sm">`：z 变换后的 ROC

坐标轴换成 z 分数（用 `Utils.zScore`），ROC 变成一条**直线**。
下面配一句：

> 坐标轴转成 z 分数后，ROC 变成直线。等方差时斜率 = 1。

**这一张只画直线和当前点就行**，不用做 σ 滑块。
