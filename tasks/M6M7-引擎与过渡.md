## M6-b：`js/engine.js`

游戏状态机。

```js
window.Engine = {
  start: function () { ... },     // 从说明页点「开始第一轮」时调用
  respond: function (responded) { ... },  // 玩家点两个按钮时调用
};
```

### 要实现的流程

```
start()
  ↓
startRound(1)
  ↓  本轮试次：nSignal 个信号 + nNoise 个噪音，用 Utils.shuffle 打乱顺序
  ↓
nextTrial()
  ├─ 从 PatientGen.generate({ hasSignal, dPrime, rng }) 取一位患者
  ├─ 记下开始时间（performance.now()）
  ├─ PatientCard.render(容器, patient, { reveal: false })
  ├─ 按钮启用
  ↓
玩家点击 → respond(responded)
  ├─ rtMs = performance.now() - 开始时间
  ├─ outcome = Scoring.outcomeOf(patient.hasSignal, responded)   ← ★ 唯一允许读 hasSignal 的地方
  ├─ 计数 +1，把 Trial 对象推进本轮的 trials 数组（结构见契约 4.2）
  ├─ PatientCard.render(容器, patient, { reveal: true, outcome: outcome })
  ├─ 按钮禁用
  ├─ 停 1200ms
  ↓
还有下一位 → nextTrial()
本轮结束 → finishRound()
  ↓
finishRound()
  ├─ roundResult = Scoring.summarizeRound(round, trials, roundConfig)
  ├─ Store.pushRound(roundResult)
  ├─ 第 1 轮结束 → RoundScreen.show(1, 2, roundResult.counts.M, 回调)
  ├─ 第 2 轮结束 → RoundScreen.show(2, 3, roundResult.counts.M, 回调)
  └─ 第 3 轮结束 → showScreen('results')      ← 现在先直接跳，M8 会接上
```

### 细节要求

- **序列生成**：本轮 `nSignal` 个 `true` + `nNoise` 个 `false`，用 `Utils.shuffle`
  打乱。**不许用"每次都 50% 随机"** —— 那样每轮实际的信号数会有波动，
  P(S) 就不是精确的 0.5 了，三轮之间也没法比。
- **rng**：本轮用一个固定的假 rng 对象传给 `PatientGen.generate`，
  这样出问题时你能复现同一批患者。建议实现一个极简的种子随机数发生器
  （比如 mulberry32，十几行），放在 `engine.js` 里。
- **按钮**：`screen-game` 里那两个按钮，现在 onclick 指向的是 M1 的假流程。
  改成 `Engine.respond(true)` / `Engine.respond(false)`。
  判断期间按钮要 `disabled`，否则玩家能连点两次。
- **进度显示**：游戏屏要显示「第 N 轮 · 轮次名」和「患者 07 / 30」。
  第 N 轮的名字从 `ROUNDS[round-1].name` 读。
- **计数显示**：显示已记录的击中/误报数（沿用 M1 已有的元素）。
- **计时**：反馈停留 1200ms 用 `setTimeout`。**如果玩家在 1200ms 内又点了，
  要忽略**（靠按钮 disabled 挡）。
- **浏览器的 rng**：`PatientGen.generate` 的 rng 参数如果你不用，可以不传，
  但**要留出这个口子**（即调用时把 rng 传进去），方便以后加"复现"功能。

## M7：`js/round.js`

轮次过渡屏。

```js
window.RoundScreen = {
  // finishedRound: 1 | 2
  // nextRound:     2 | 3
  // missCount:     上一轮的漏报数（用来替换文案里的占位符）
  // onNext:        「进入下一轮」按钮的回调
  show: function (finishedRound, nextRound, missCount, onNext) { ... }
};
```

渲染内容：

```
第 {finishedRound} 轮结束

{ROUNDS[nextRound-1].intro 的文案}

[ 进入第 {nextRound} 轮 → ]
```

**占位符替换**（文案在 `config.js` 的 `ROUNDS[n].intro` 里）：

- `{round2M}` → 替换成 `missCount`
- `{n}` → 替换成 `Math.max(1, Math.floor(missCount / 2))`
  （"其中几位病情恶化"）

**只替换这两个**，别的不许动。用 `String.prototype.replace` 就好。

样式：
- 过渡屏要**有分量感** —— 这是玩家情绪最重的一屏（第二轮被告知资源紧张、
  第三轮被告知漏了人）
- 文案用 `<pre>` 或 `white-space: pre-line` 保留换行
- 建议把数字（漏报几位）**放大显示**，这比埋在一段话里有冲击力
- 第 2 轮的标题前缀是 `⚠`，第 3 轮是 `📋`，文案里已经带上了
