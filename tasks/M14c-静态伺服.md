## 一、加静态文件路由

### 要伺服什么

**项目根目录**（也就是 `server/` 的上一级）里的：

```
index.html
admin.html
js/**
styles/**
docs/**      （可要可不要，别把 docs 暴露出去也行 —— 你决定，说一声）
```

**不要伺服**：

- `server/**`（后端自己的代码和数据库**绝对不能**被下载到）
- `tasks/**`（施工任务书，是内部文档）
- `CONTRACT.md`（同上）
- `.git/**`
- 任何以 `.` 开头的文件

### 路由怎么写

**顺序最关键**：`/api/*` 的路由必须**先注册**，静态路由的兜底放最后。

```python
import os
from flask import send_from_directory

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))   # 项目根目录

# ★ 已有的 /api/... 路由都在这里，别动它们

@app.route('/')
def _index():
    return send_from_directory(ROOT, 'index.html')

# 兜底：其它路径都当成静态文件去项目根目录找
@app.route('/<path:path>')
def _static(path):
    ...
```

**`_static()` 里必须做的三件事**：

1. **挡目录穿越**：请求 `/../../etc/passwd` 这种要拒掉。
   用 `os.path.realpath` 解析后确认结果仍在 `ROOT` 里面 ——
   **不要只靠字符串判断 `'..' not in path`**，那挡不住编码变体。
2. **白名单顶层目录**：只允许从 `js/`、`styles/` 开头的路径，加上
   `index.html` / `admin.html` 这两个根文件。其余一律 404。
3. **找不到就 404**，不要抛 500。

**`send_from_directory` 本身就有防穿越检查**，但白名单这一层还是要加 ——
**它挡的是"能访问到什么"**，不是"能不能穿越"。

### 关于 `index.html` 的缓存

开发时最烦的就是浏览器缓存旧的 JS。**在静态响应上加这两个头**：

```python
resp = send_from_directory(...)
resp.headers['Cache-Control'] = 'no-cache, no-store, must-revalidate'
return resp
```

（作业场景，不做长缓存优化。**让人永远看到最新文件比省那点流量重要得多** ——
今天已经因为缓存被坑过两次了。）

### 启动信息

`app.run()` 之前打印的地址里，把**学生端和教师端的完整网址**都写出来：

```

  教师端  http://127.0.0.1:5055/admin.html

```

## 自测

```bash
cd ~/Documents/工程心理学作业/sdt-lab/server
python3 app.py
```

**别关这个终端**，另开一个，逐条跑：

```bash
# ① 学生端能打开
curl -s -o /dev/null -w '%{http_code}  %{content_type}\n' http://127.0.0.1:5055/

# ② 教师端能打开
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/admin.html

# ③ 静态资源能拿到
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/js/patient.js
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/styles/tokens.css
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/js/vendor/echarts.min.js

# ④ ★ 接口没被静态路由抢走
curl -s -X POST http://127.0.0.1:5055/api/admin/login \
  -H 'Content-Type: application/json' -d '{"password":"admin123"}'

# ⑤ ★ 后端代码和数据库【绝对不能】被下载
echo -n "  server/app.py      → "; curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/server/app.py
echo -n "  server/sdt.db      → "; curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/server/sdt.db
echo -n "  tasks/             → "; curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/tasks/M14-后端.md
echo -n "  CONTRACT.md        → "; curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/CONTRACT.md

# ⑥ ★ 目录穿越
echo -n "  ../../etc/passwd   → "; curl -s -o /dev/null -w '%{http_code}\n' 'http://127.0.0.1:5055/../../etc/passwd'
echo -n "  %2e%2e 编码变体    → "; curl -s -o /dev/null -w '%{http_code}\n' 'http://127.0.0.1:5055/%2e%2e%2f%2e%2e%2fetc%2fpasswd'

# ⑦ 不存在的文件 → 404 而不是 500
echo -n "  /nope.js           → "; curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:5055/nope.js

# ⑧ 缓存头
curl -sI http://127.0.0.1:5055/js/patient.js | grep -i cache-control
```

**期望**：

| # | 期望 |
|---|---|
| ① ② | **200**（content-type 是 text/html） |
| ③ | 全 **200** |
| ④ | **200** 且返回 JSON（不是 404、不是 HTML） |
| ⑤ | **全部 404** ← 这一条最重要，泄漏了就是事故 |
| ⑥ | **404 或 400**，绝不能返回文件内容 |
| ⑦ | **404**（不是 500） |
| ⑧ | 有 `no-cache` |
