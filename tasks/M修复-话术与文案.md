## 一、`js/results.js` + `js/lab/roc.js`：话术按摆幅选 ★

### 问题

这两处都有**写死的断言**，只有数字是动态的：

```
玩家真实数据：  d′ = 0.54 / 0.98 / 1.79      ← 摆幅 1.25，变化巨大
页面却说：      「几乎没变」                  ← 假话
```

**而且它把相反的证据和固定的结论摆在同一个屏幕上** —— 学生会觉得页面在糊弄他。

### 规则（契约 3.8，两个文件用同一套）

**d′**

| 摆幅 | 评语 |
|---|---|
| < 0.35 | 「几乎没变」 |
| 0.35 ~ 0.70 | 「有点起伏」 |
| **> 0.70** | 「**变化明显**」+ **整段结论换成下面那套** |

**c**

| 摆幅 | 评语 |
|---|---|
| < 0.20 | 「几乎没动」 |
| 0.20 ~ 0.50 | 「有点移动」 |
| **> 0.50** | 「**大幅移动**」 |

**准确率**

| 摆幅 | 评语 |
|---|---|
| < 8 个百分点 | 「差不多」 |
| 8 ~ 15 个百分点 | 「有点差别」 |
| **> 15 个百分点** | 「**差别不小**」 |

### d′ 摆幅 > 0.70 时，结论块整段换掉

**不要在"d′ 没变"的前提下再念一遍数字。** 换成：

> 你的 d′ 从 **{最小}** 涨到 **{最大}** —— 这**不是**"代价改变了能力"。
>
> 最可能的原因是**练习效应**：前几轮你还在摸索怎么读生命体征，
> 后面已经熟练了。纵向实验里很常见，所以正式实验都会先做一轮练习再开始计分。
>
> 不过 c 的变化仍然说明问题：**{c 的那段结论照旧}**

**★ 最后那句不能丢** —— 即使 d′ 变了，**c 的结论仍然成立**，
不要连着一起扔掉。这是两个独立的维度。

### 阈值不要硬编码在四处

两个文件都要用同一组阈值。**写成一个常量对象**，或者放在 `config.js` 里
（`config.js` 不归你，那就各自文件顶部定义一份、数值必须一致，并加注释说明）。

## 二、`js/lab/payoff.js`：一处事实错误

**位置**：第 197 行附近

**原文**：
```
第三轮只改了 C(M)，最优 β 掉到 0.30
```

**问题**：**事实不对。** 三轮支付矩阵实际是：

```
              V(H)   C(M)   C(FA)   V(CR)
第一轮        +10    −10     −10     +10
第二轮        +10    −10     −30     +15
第三轮        +10    −40     −10      +5     ← V(CR) 也变了
```

**第三轮改了两个格子：C(M) 和 V(CR)。**

（**结论方向是对的** —— V(CR) 调低也推着 β 变小、人更宽松，和 C(M) 调高同向。
所以「漏报的代价上升，理性的人就该更宽松」没错，只是**前半句的事实描述不准**。）

**改成**：
```
第三轮把 C(M) 从 −10 加到 −40，同时把 V(CR) 从 +10 降到 +5，最优 β 掉到 0.30
```

**★ 但不要写死数字** —— 这三个数应该从 `ROUNDS[2].payoff` 和 `ROUNDS[0].payoff`
动态读出来（用户可以在面板里改支付矩阵，写死了就不跟着变）。

**顺便确认**：第二轮的「只改了 C(FA) 和 V(CR)」**是准确的**，不用动。

## 三、`js/lab/vigilance.js`：一处自相矛盾

**原文**（占位说明那里）：
```
急诊分诊员值夜班 —— 持续盯着分诊台 6 小时会发生什么？
```

**问题**：面板自己写着「8 个 15 分钟时段」，那是 **2 小时**。标题说 6 小时，**对不上**。
（Mackworth 钟实验原版就是约 2 小时。）

**改成**：
```
急诊分诊员值夜班 —— 持续盯着分诊台 2 小时会发生什么？
```

**整个文件里搜一遍「6 小时」，全部改掉。**

## 四、顺手检查一件事

另一个会话报告说：`Chart.base()` 里带了 `legend` 的 `textStyle`，
**ECharts 只要看见 option 里有 legend 就会自动生成图例**，
默认落在图的下缘，**正好压住 x 轴刻度**。

`js/lab/payoff.js` 和 `js/lab/vigilance.js` 已经处理了。
**请检查 `js/results.js` 和 `js/lab/roc.js` 有没有被同样的问题影响**：

- 如果没有图例需求 → 加 `legend: { show: false }`
- 如果需要图例 → 显式给 `legend.top`，别让它压住坐标轴

**看图确认，别只看代码** —— 这类问题在代码里看不出来。
