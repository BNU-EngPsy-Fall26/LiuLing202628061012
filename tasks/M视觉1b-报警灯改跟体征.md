## 改什么：灯跟着**体征**走，不跟 `severity`

### 为什么这样改

| 理由 | 说明 |
|---|---|
| **更真实** | 真实监护仪就是**根据显示的读数**报警的 —— 没有哪台机器能读到 ground truth |
| **不泄漏** | 灯只汇总**已经显示给玩家的信息**，一个比特都不多 |
| **顺带解决你提的第二个问题** | 灯不再读 `tierRules.bounds`（那是给"主诉抽哪一档"用的），语义耦合自然断了 |

### 具体规则

**灯的档 = 五项生命体征里【最差的那一档】。**

分档阈值**和 `patient-card.js` 完全一致**（契约 2.4）：

```js
// 每项算出自己的档：0 = 正常 / 1 = 需观察 / 2 = 危急
// 取五项里的最大值（最差的那一个）
var band = Math.max(
  bandOf(vitals.temp,          TEMP_RANGES),
  bandOf(vitals.hr,            HR_RANGES),
  bandOf(vitals.sbp,           SBP_RANGES),
  bandOf(vitals.spo2,          SPO2_RANGES),
  CONSCIOUSNESS_BAND[vitals.consciousness]     // 清醒 0 / 嗜睡 1 / 昏睡·昏迷 2
);

// 然后：0 → normal（绿常亮）· 1 → watch（黄慢闪）· 2 → danger（红快闪）
```

**★ 用【全部五项】，不是面板上那三项。** 理由：灯是"这位患者整体看起来怎么样"的汇总，
而卡片上显示的就是五项。只用三项的话，会出现"体温明显异常、但灯是绿的"这种不一致。

### 闪烁速度：**保持不变**

现在中间档 1s、危险档 0.5s —— **别动**。只换"颜色由什么决定"。

**改法**：让 `patient-card.js` 把阈值表导出。

```js
// js/patient-card.js，在 return { render: render }; 那一行前面加一行
return { render: render, VITAL_RANGES: VITAL_RANGES };
```

**然后 `monitor.js` 改成从 `window.PatientCard.VITAL_RANGES` 读，删掉自己抄的那份。**

**★ 这是本次唯一允许你动 `patient-card.js` 的地方 —— 只加导出，不改任何逻辑。**

**兜底**：`PatientCard.VITAL_RANGES` 不存在时（比如单独加载 monitor.js），
用一份硬编码的兜底值并在控制台 `console.warn` 一句。

## 自测（★ 按 §10 六字段）

### ① ★ 灯不再泄漏 —— 这条最关键

**【测什么】** 灯的颜色**完全由 `vitals` 决定**，和 `severity` / `hasSignal` 无关
**【怎么测】** 造两组患者：**同样的 `vitals`，但 `severity` 一个高一个低**（甚至 `hasSignal` 一真一假）——
两组的灯色**必须相同**
**【期望】** 完全相同
**【它怎么失败】** 还有人从 severity 读灯
**【★ 怎么确认它真的会失败】** 变异：把 `alarmBand` 改回 `severity` 版 →
**这条断言必须红**（因为两组 vitals 相同、severity 不同，灯会不一样）

### ② 灯和卡片的分档一致

**【测什么】** 灯是"五项里最差那档"，且用的阈值和卡片一致
**【怎么测】** 36 例数值扫描（含全部边界值：60/100、90/140、95/94…）+
`consciousness` 四个词全覆盖，逐例比对"灯色"和"卡片上最差那格的颜色"
**【期望】** 逐例一致
**【★ 怎么确认它真的会失败】** 把 `spo2` 的阈值改成 90/80（错值）→ 边界那几例必须红

### ③ 三档灯都还能出现

**【测什么】** 不是所有患者都变同一个颜色
**【怎么测】** 跑 500 位随机患者，统计三档各出现多少次
**【期望】** 三档都出现，且分布合理（观察档应该最多 —— 因为"五项里有一项偏离"很容易）
**【★ 怎么确认它真的会失败】** 把 `Math.max` 改成 `Math.min`（取最好那档）→
分布立刻塌向"几乎全是绿"，断言必须红

### ④ 不再读 severity

**【测什么】** `monitor.js` 里 `severity` 出现 0 次（代码行）
**【怎么测】** 去注释后 grep
**【★ 怎么确认它真的会失败】** 随便找一行写个 `patient.severity` → 必须红

### ⑤ ★ 回归：波形/数字/布局一个字没变

**【测什么】** 上一波那几条断言全部照旧通过
（`frozen` 铁律自查、波形在动、12 个数值扫描、布局不跳、窄屏不溢出、删掉面板照样跑）
