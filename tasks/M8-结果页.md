## 这一屏的任务

**它是整个实验的教学高潮。** 玩家刚玩完三轮，这一屏要让他**亲眼发现**：

> 我的分辨能力（d′）三轮几乎没变，变的只是我的标准（c）。

**别用大段文字讲这个道理 —— 用表让他自己看出来。**

## 接口

```js
window.Results = {
  // index.html 在每次进入结果页时调用它（见 showScreen 里那几行）

`Store.student.name` 是玩家姓名（游客模式为 null）。

### 2. ★★★ 三轮对比表 —— 这是全页最重要的东西

严格按契约 **3.6 节**那张表的列：

```
               P(H)   P(FA)   d′      c      准确率
第一轮 常规值班  0.76   0.21   1.51   +0.05    78%

**要求**：轮次名从 `ROUNDS[n-1].name` 读，不要写死。

### 3. ★ 三条注释（表下面的视觉提示）

**这是让人"看出来"的关键，务必做**：

指向 `d′` 那一列，写「**几乎没变**」
指向 `c` 那一列，写「**大幅移动**」
指向 `准确率` 那一列，写「**差不多**」

可以用带箭头的注释行（像上面那样），也可以用三个小色块 + 一行字。
**配色**：d′ 那列用 `--c-text-dim`（不起眼），c 那列用 `--c-accent`（醒目）。

### 4. 结论块

## 自测

结果页的数据依赖玩家真的玩过三轮。有两条路：

**方式一（推荐）**：手动在控制台塞假数据，然后调 `Results.render()`：

```js
Store.setStudent('202628061234', '张三');
Store.setMode('standard');
Store.clearRounds();
// 用契约 3.6 的三组计数造 RoundResult
Store.pushRound({ round:1, roundName:'常规值班',
  counts:{H:12,M:3,FA:3,CR:12},
  metrics:{pH:0.781,pFA:0.219,dPrime:1.55,c:0.00,beta:1.00,accuracy:0.800,meanRtMs:2140} });
// 第二轮 H8/M7/FA1/CR14，第三轮 H14/M1/FA6/CR9，自己按契约 3.6 填
showScreen('results');
```

**期望**：三行数字和契约 3.6 那张表**完全一致**。

**方式二**：真玩一轮快速版（约 4 分钟）。

**验收**：
1. 三轮对比表的数字格式正确（d′ 两位小数、c 带正负号、准确率百分比）
2. 三条注释在正确的位置
3. 结论块里的数字是玩家自己的，不是样例数字
4. 三个按钮都能用，`clearRounds()` 之后 `Store.rounds.length === 0` 但 `Store.student` 还在
5. 控制台无红字
6. 手机上表格能看
