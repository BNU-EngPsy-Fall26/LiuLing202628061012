## 一、为什么要改 —— 我量过了

你上一份报告里担心"波形是 severity 的另一条通道"。**我把那个担心量化了：**

```
一个只看「波形档位」的观察者（规整 / 早搏 / 不齐 三档，切点 0.4/1.1）：

        d′ = 1.06      准确率 76.0%

对照：理想观察者用完整 severity  →  d′ = 1.50，准确率 77.3%
```

**76.0% vs 天花板 77.3% —— 玩家只看波形就能拿到接近满分的成绩，体征都可以不看了。**

**你的担心是对的，而且比估计的严重。**

我又算了加多少漂移能压下去：

```
漂移   0%  →  d′ = 1.06   76.0%
漂移  30%  →  d′ = 0.90   72.0%
漂移  40%  →  d′ = 0.85   70.7%
漂移  60%  →  d′ = 0.75   68.2%
```

**加漂移有用，但压不干净**（切点 0.4/1.1 正好落在最优判定阈值附近，
所以掺了噪声它仍然是个不错的线索）。

**结论**：**加 40% 漂移，把 d′ 从 1.06 压到 0.85 左右** ——
和主诉（30% 漂移）一个量级就行，**别指望压到 0**。
**剩下的靠系统 d′ 那个旋钮**（那是最后一件事，不在这份任务书里）。

## 二、① 加 40% 漂移

### 规则

```js
// 形态档位：先按 severity 定（切点 0.4 / 1.1，和现在一样）
// 然后以 40% 的概率漂到相邻档（方向随机，两端夹住）
```

**和主诉用的是同一套机制**（契约 3.3.1）—— 只是比例不同：

| | 漂移 |
|---|---|
| 主诉 | 30% |
| **波形** | **40%** ← 新增 |
| 来院方式 | 50% |

### ★ 漂移必须由 `patient.id` 决定，不能用随机数

**和现在的心搏序列同一个种子。**

理由（三个都不能少）：
1. **同一位患者重渲染时波形必须一致** —— 否则 `frozen:true` 那套铁律自测会不稳
2. **不引入新的随机性来源** —— 铁律那套照旧成立
3. 不需要改 `Monitor.render` 的接口（不加 `opts.rng`）

**★ 铁律照旧**：漂移只看 `severity` 和 `patient.id`，**不许读 `hasSignal`**。

## 三、② 第三档：让"间距乱"占主导，早搏降下来

### 你自己提的那个方案，我采纳了

> 第三档现在是"早搏多"，不只是"节律乱"……
> 如果你要的是"底下那串常规拍自己就乱得很明显"，那就得把第三档的早搏降回每 8~10 拍，
> **让 ±30% 抖动独占画面**。

**理由**（我加一条你没说的）：

```
"3 个宽大波算多吗？"
        ↓
玩家【没有基准】—— 除非他记着前面二十几位都是 0~1 个
        ↓
而"节奏整不整齐"是【不需要基准的】—— 眼睛一看就知道
```

### 改成

| 档位 | 底下的常规拍 | 早搏 |
|---|---|---|
| **规整** | 等间距（±5%） | 无 |
| **偶发早搏** | 等间距（±6%） | **每 8~10 拍一个** |
| **明显不齐** | **±30% 抖动**（每个间隔独立） | **也降到每 8~10 拍一个** ← 改这里 |

**第三档的"乱"由底下的常规拍自己承担，不靠数早搏个数。**

**（现在第三档是每 4~6 拍一个早搏 —— 改成 8~10。）**

**`jitter` 保持 0.40**（那个数是按 `1/√(0.65²+0.35²)` 折算出来的，实测落在 ±30% 上，别动）。

## 四、③ ★ 量化验收 —— 这条最重要

**你上一版的所有断言都是"和内部状态比"或"和像素比"。这次要加一条【和理论比】的：**

### 【测什么】只看波形档位这一个线索，能到多少 d′

**【怎么测】** 跑 ≥ 20000 位随机患者（`PatientGen.generate`，一半信号一半噪音），
对每一位**按你现在画出来的形态判定它的档位**（规整 / 早搏 / 不齐），
然后：

```
把「档位 ≥ 某档就说有信号」当成一个观察者，
穷举两种判定（≥中档 / ≥重档），取 d′ 大的那个。
用契约 4.5 的对数线性修正算 pH / pFA，再算 d′。
```

**★ 关键：判档必须【走真实路径】** —— 用你画波形时用的那个函数（含漂移），
**不要另写一份"理想档位"**。否则测的是别的算法，不是画面上那条线。

**【期望】**

| | |
|---|---|
| **改之前** | d′ ≈ **1.06**（准确率 76.0%）—— 我已经算过，复现一下对个数 |
| **改之后** | d′ **≤ 0.90**，准确率 ≤ 72% |
| **下限** | 别低于 **0.6** —— 低于它说明波形几乎没信息量了，那就白画了 |

**【★ 怎么确认它真的会失败】** 把漂移改成 0 → 断言必须红（会回到 1.06）。

### 为什么要这条断言

**因为它把"像不像真心电图"换成了一个数字。**

「波形画得对不对」没法自动验（要懂心电），
但「波形有没有把游戏变简单」**能验，而且这才是真正要防的**。

**以后谁改波形，跑这一条就知道有没有越线。**
