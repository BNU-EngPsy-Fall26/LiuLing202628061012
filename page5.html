d'
1.90

辨别力指标，表示信号分布与噪音分布之间的距离。d'越大，两者越容易区分。

d' = z(H) - z(FA)
β
1.46

反应偏向的似然比指标。β=1 表示标准中性，β>1 表示偏严格，β<1 表示偏宽松。

β = fSN(xc) / fN(xc) = ed'c
c
0.20

判定标准相对两分布中点的位置。c>0 表示偏严格，c<0 表示偏宽松。

c = -0.5 × [z(H) + z(FA)]
A'
0.895

非参数辨别力指标，可理解为 ROC 曲线下面积。0.5 接近随机，1 表示完全辨别。

A' = 0.5 + [(H-FA)(1+H-FA)] / [4H(1-FA)]
